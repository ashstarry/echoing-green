# Echoing Green secure Jev gateway

GitHub Pages serves the browser town; this independent Sites service performs one bounded Jev request per submitted wish. No continuous world simulation runs here. Wonderline remains unchanged.

Required runtime Secret: `OPENROUTER_API_KEY`. Public configuration: `ALLOWED_ORIGIN=https://ashstarry.github.io`.

Provider model and endpoint are fixed server-side. Body size, input length, normalized state, timeout, finite choices and output validation are enforced. Requests and provider responses are not persisted or logged. Errors never include provider response bodies or credentials. CORS accepts only the configured frontend origin. CORS is not authentication; the public endpoint is protected by per-IP and concurrency limits local to a Worker isolate, not a guaranteed global spending cap. A broader launch may need durable quotas or visitor verification.

Build and publish through the Sites tools. Never include environment files or credentials in source archives. The pure semantic core is derived from the tested CP27 planner; versioned town behavior remains in the frontend.
